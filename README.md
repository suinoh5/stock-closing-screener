# 🚀 [보강판] 종가매매 실전 자동 스크리너 (Strategy 3)

한국 주식시장(코스피/코스닥) 종가매매(14:50~15:20) 전략을 기반으로, 실제 180영업일 백테스팅을 거쳐 검증된 **승률 55.8% 및 손익비 1.19 최적화 필터링 알고리즘**을 적용한 자동화 시스템입니다.

GitHub Actions를 통해 컴퓨터가 꺼져 있어도 **매일 평일 15:10(KST)에 클라우드에서 자동으로 실행**되어 당일 최적의 주도주 리포트를 내 Gmail로 발송합니다.

---

## 🎯 4대 핵심 전략 필터링 규칙 (전략 3)
1. **거래대금 300억 ~ 500억 이상**: 진짜 돈이 몰리는 시장 주도 대장주 선별
2. **당일 상승률 +3.0% ~ +15.0% 제한**: 이미 너무 많이 오른 과열 급등주(+20%↑) 제외
3. **윗꼬리 $\le$ 2.0% 이내 엄수**: 장 막판까지 매수세가 살아있는 종가 고가형 캔들만 매수
4. **전일 고가 돌파 & 5일선/20일선 정배열 & 거래량 200%↑ 폭증**
5. **익일 시초가 대응**: 1차 목표가 +2.0% 분할 익절, 2차 목표가 +3.5%, 손절선 -2.5%

---

## ⚙️ GitHub Secrets 설정
본 레포지토리의 `Settings > Secrets and variables > Actions`에 아래 환경변수를 등록해야 합니다.

- `GMAIL_USER`: 알림 발송용 Gmail 주소
- `GMAIL_APP_PASSWORD`: Google 계정 보안에서 발급받은 16자리 앱 비밀번호
- `TARGET_EMAIL`: 알림을 수신할 이메일 주소
